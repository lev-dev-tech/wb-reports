# Отчеты Wildberries

Закрытая страница с отчетами по кабинету WB: заказы и выкупы по дням, товары, реклама, остатки FBS, регионы, выводы. Хостинг - GitHub Pages, данные обновляются сами каждые 3 часа.

## Как устроена защита

- Токен WB лежит только в секретах репозитория (`WB_API_TOKEN`). В браузер и в файлы репозитория он не попадает.
- GitHub Actions по расписанию берет данные из API WB и шифрует их: AES-256-GCM, ключ из пароля через PBKDF2-SHA256, 600 000 итераций. На сайте лежит только шифровка `data.enc.json`.
- Страница расшифровывает данные в браузере после ввода пароля (`DASHBOARD_PASSWORD`). Без пароля в файле ничего нельзя прочитать, даже если скачать его.
- Строгая CSP: скрипты только с этого сайта, никаких внешних библиотек и счетчиков. `noindex` и `robots.txt` - поисковики страницу не индексируют.
- После неверного пароля растет задержка. Расшифрованный ключ живет только в текущей вкладке и стирается кнопкой "Выйти" или закрытием вкладки.
- Пароль должен быть длинным (от 16 символов, сборка короче не примет): от его стойкости зависит вся защита.

## Подключение

1. Создать пустой репозиторий на GitHub и запушить этот код в ветку `main`.
2. Settings → Secrets and variables → Actions → New repository secret:
   - `DASHBOARD_PASSWORD` - пароль для входа на страницу;
   - `WB_API_TOKEN` - токен WB (кабинет продавца → Настройки → Доступ к API). Достаточно токена "только чтение" с категориями: Статистика, Продвижение, Маркетплейс, Контент.
3. Settings → Pages → Source: **GitHub Actions**.
4. Actions → "Обновить отчет" → Run workflow. Пока токена WB нет, публикуются демо-данные.

## Локальная проверка

```
DASHBOARD_PASSWORD=... node scripts/build.mjs --demo
python -m http.server -d site 8080
```

## Что откуда

- Заказы и выкупы - `statistics-api` `/api/v1/supplier/orders` и `/sales` за 30 дней.
- Реклама - `advert-api` `/adv/v1/promotion/count` и `/adv/v3/fullstats` (кампании в работе, на паузе и завершенные).
- Остатки - `marketplace-api` `/api/v3/warehouses` и `/api/v3/stocks/{склад}` по баркодам из `content-api` `/content/v2/get/cards/list`.
- Если у токена нет доступа к какому-то разделу, остальное работает, а внизу страницы видно, каких данных нет.
